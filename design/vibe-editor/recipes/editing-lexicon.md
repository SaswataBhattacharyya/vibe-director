# Editing vocabulary

| Everyday request | Concrete interpretation to review |
| --- | --- |
| Punchier | Trim pauses, start nearer the action, shorten holds; propose exact ranges. |
| Let it breathe | Longer reaction/establishing holds; preserve meaningful silence. |
| Keep the words | Preserve dialogue content and selected source soundtrack. |
| Cinematic | Ask which observable change: framing, lighting, colour, pacing or sound; not a preset look. |
| J-cut / L-cut | Next audio begins before its image / previous audio continues after the cut; requires a separate audio edit adapter. |
| Match cut | Connect similar shapes, action or meaning across shots; select concrete boundaries. |
| Spiritual | Ask or use THIS style's confirmed interpretation; never assume a religion, instrument or tempo. |

User intent overrides these examples. Unsupported operations become explicit specialist handoffs.
