# Decisions, risks and only genuine unknowns

## Decisions locked by owner instructions
- Codex-like Director: plan first, implementation only after user approval.
- Real computer/code/runtime tool capability—not merely LLM advice.
- Keep original left nav and Media Prep intact.
- Manual stages independent and skippable.
- Project-specific knowledge graph + tool graph/glossary + skill registry.
- Creative profile jackets composable and optional.
- Editor is delegated specialist sharing actual tools; HyperFrames remains current render path.
- OpenMontage/Backlot optional delegation/integration; not prerequisites or replacement engines.
- H3 user workflow: max 15 seconds, strict <7000 characters for R2V/FFLF; actual on-disk contract strict below 7000 Unicode codepoints.

## To discover in the live checkout, NOT blockers to writing plan
- The actual current Git branch/commit and uncommitted modifications, especially updated Editor code.
- Actual GitHub branch availability vs local code mismatch. Prefer user's local source for implementation.
- Available computer/desktop automation host: Linux graphical session, Playwright/Chromium, Blender, sandboxing, and local system permissions.
- Provider/reasoning model tool-call support vs structured-action fallback.
- Current official OpenMontage/Backlot/HyperFrames Studio versions, licenses and embeddability.
- Live ComfyUI node compatibility and ability to support H3 turbo-only pipeline without changing older frozen workflow digest.
- How user wishes to authorize budgets, GPU generation limits and code edits; propose safe defaults if unanswered.
- Which QA analyzers actually inspect audio/video and produce trustworthy segment evidence.

## Non-goals for v1
- Replace entire project DB with a new graph database; overwrite immutable takes; bypass GPU safety; install unreviewed external agents by default; make a universal unrestricted shell tool; pretend third-party GUIs are embeddable; rewrite Media Prep.
