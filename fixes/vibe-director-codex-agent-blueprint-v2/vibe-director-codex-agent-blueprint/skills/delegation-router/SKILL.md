# Delegation Router
Discover target capabilities, current runtime and typed handoff. Native app tool preferred if equivalent. HyperFrames trusted renderer is already integrated; Studio embed remains optional. Backlot provides production monitoring, not editable storyboard. OpenMontage is optional external researcher/montage adapter after license/security/versions check. Delegate only scoped tasks with approved inputs, resource budget, expected output and project owner; observe actual progress and register verified outputs. If unavailable, say unavailable and use native path. Parent Director remains responsible for final film quality. See `../../08_EDITOR_HANDOFF_AND_DELEGATION.md`.
