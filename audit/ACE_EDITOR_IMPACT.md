## Changes and review

- Editor offers files or a folder (all nested subfolders), selected-kind filtering, selection counts/select all shown, named sorting, cards/list/carousel, previews and guarded permanent deletion. Managed library copies/references are used; choosing a folder does not modify source files. Unsupported backend formats still follow existing validation.
- Selected assets attach or drag into chat. Exact duplicate ranges are suppressed; different ranges remain allowed. File drop/paste and partial-upload recovery remain. Hover/focus × and touch-visible × detach only.
- Session and source controls use fixed popovers, including Escape/focus behavior and narrow-screen sizing. Standalone story-context setup was removed while saved ownership is preserved.
- Output path and chooser use existing grants/relink/export paths. Missing folders do not silently fall back. A typed shared path is applied with Use this folder.
- ACE fresh/new sessions open Create/Generate. Restored training intent selects Fine-tune; settings/datasets are retained. Tab changes during active work cannot create intent/content mismatch.
- Review caught and fixed first-import async refresh, a deletion result overwritten by refresh status, and the recording reuse path after removing workspace setup. Existing stale test selectors/obsolete workspace fixtures were corrected.

No further actionable defects were found in the bounded reviewed patch. Validation limits above remain; this is not whole-app acceptance.
