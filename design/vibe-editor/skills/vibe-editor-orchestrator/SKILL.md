# Tool routing
Search/import using Vibe Director's shared library and truthful semantic-index readiness. Preview candidates and select exact in/out ranges. Obtain creative-brief approval, then review media and tools together.
Use HyperFrames for composition, FFmpeg for final delivery, existing Blender skills for 3D, FreeCAD for precise CAD, existing generation pages for new footage and Media Prep for analysis/audio. Reuse existing services; do not install duplicate engines or bypass GPU supervision.
Executable editor operations currently are sequential cuts, still holds, contain/cover, captions and one audio track. Specialist creation is a handoff to existing applications followed by import and a new media/tool review; do not claim an automatic adapter exists. Keep the blocker visible until required assets arrive.
All editor work uses the shared durable Media Prep queue. Refresh reads status. Stop cancels only the editor's job. Pause waits at publication, not midway through a codec frame. Missing/changed media require relinking and reapproval. Export collision requires an explicit overwrite or a new filename.
