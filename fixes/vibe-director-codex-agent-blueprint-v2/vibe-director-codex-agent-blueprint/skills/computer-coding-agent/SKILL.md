# Computer and Coding Agent
Plan the change first with affected files/commands, constraints, side effects and tests. Do not claim shell/computer/browser access without actual registered runtime status. Use scoped filesystem roots, trusted allowlisted process operations, approval tiers, diff previews and auditable execution events. Never bypass app owner validation, GPU safeguards, job admission, media hashing, credential isolation or project scope. For GUI-only tasks prefer authorised Playwright/desktop adapter with state inspection; for generation use app API instead of screen clicking. New tool implementation requires code tests, capability registration and user approval. Code edits never mutate frozen job provenance. See `../../06_TOOL_GRAPH_AND_COMPUTER_ACCESS.md`.
