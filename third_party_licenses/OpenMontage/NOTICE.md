The optional installer downloads the unmodified Backlot UI/server and their required Python helpers into ignored local runtime storage. The installed source and license remain available there. Vibe launches this runtime separately against a disposable, read-only mirror. No upstream UI/server source is copied into the first-party frontend bundle. Native server authentication is supplied by Vibe's separate launcher. Keep upstream notices and corresponding source available when distributing this integration.
