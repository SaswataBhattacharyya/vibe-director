## models.3d — TRELLIS.2 and Pixal3D image-to-3D

**Choose when:** Create a 3D object from images or aligned multi-view inputs.

**UI:** #/image-to-3d or #/image-to-3d-pixal3d

**Inputs:** Backend, single/batch mode, uploaded inputs, optional view profile/confirmation, preset/settings, output grant.

**Outputs:** Per-object durable job, validated GLB and output location/viewer.

**How to use:** GET /api/trellis/state; POST upload/output-folder/jobs; GET job/model; POST cancel/resume/recover. TRELLIS multiview may need /service. Supported presets/backends differ. Text alone is not valid image-conditioned input. Blender opening is an explicit separate action.

**Source:** [TrellisPage.tsx](../frontend/src/TrellisPage.tsx), [MultiViewInputs.tsx](../frontend/src/MultiViewInputs.tsx), [trellis_studio.py](../backend/story_builder/services/trellis_studio.py), [multiview_3d.py](../backend/story_builder/services/multiview_3d.py)
