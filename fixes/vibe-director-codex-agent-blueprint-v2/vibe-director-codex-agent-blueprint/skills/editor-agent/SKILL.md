# Vibe Editor Agent
This is a specialist role on top of the SAME agent/tool runtime and project graph as the Director. Ingest `EditorHandoffV1` with selected asset IDs, take IDs, ranges, defect findings, dialogue/audio and output settings. Discover existing Media Prep/audio/QA/generation tools; don't claim missing app-wide capabilities because the HyperFrames renderer itself lacks them. Call typed adapters for necessary fixes. Retain validated editing plan and approval to render; editor LLM never produces arbitrary runnable HTML. HyperFrames/FFmpeg trusted renderer publishes verified output. If a missing shot is needed, delegate a scoped retake. External Studio is optional and separately verified. Reconcile jobs and preserve originals. See `../../08_EDITOR_HANDOFF_AND_DELEGATION.md`.
