# Text to Image and folder-based reference browser

Status: implemented locally; owner UI acceptance pending.
Updated: 2026-10-29.

## Confirmed owner decisions

- Generated images are saved **only** to the folder the user chooses. Do not keep a
  second persistent image copy in a Vibe Director workspace/library.
- The user chooses the output folder through a folder-picker popup.
- Reference images are browsed from a user-chosen PC folder, including all nested
  subfolders.
- “Delete selected” permanently deletes the selected image files from disk.
- The reference gallery has newest/oldest ordering, card/list/table views, selection
  and deselection, select all, and delete-selected controls.
- A distinct **Use as reference** action adds selected gallery images to the current
  generation request. It is enabled only for workflows that accept image inputs.
- Images can also be dragged from the gallery into the prompt chat. Chat attachments
  are removable and use the shared model selector and `/status` behavior.
- Add the same folder-backed reference gallery as a separate collapsible section
  in the right column, directly below Workflow details, on Characters, Worlds,
  and Frames.

## User journey

1. Open Text to Image, or a Characters, Worlds, or Frames page.
2. Choose a reference folder. The gallery indexes supported image files in that
   folder and its subfolders; the originals remain in place unless explicitly
   deleted through the confirmed delete action.
3. Search/browse and sort the images, change the view, and select one or more.
4. Use **Use as reference** to add selected files as generation references where the
   selected workflow supports them. Dragging a gallery image to chat attaches it to
   the chat for discussion; it does not silently attach it to the diffusion request.
5. Enter/review the prompt, set workflow parameters, and generate using the existing
   readiness/admission checks. Show progress and the generated result.
6. Choose the output folder before generation. The job uses a unique transient
   workspace isolated from story and standalone media libraries. Save the final image
   only to the chosen folder, verify its hash, and remove temporary tagged assets.

## Workflow compatibility

- Z Image and Qwen Image 2512 are text-to-image workflows; selected folder images
  cannot condition their diffusion generation. Keep **Use as reference** disabled
  and explain why while either is selected.
- Qwen Image Edit 2511 accepts one primary source plus at most two additional images
  (three total), per the current local workflow validator. Enforce this limit in the
  gallery and show selected/reference counts.
- Drag-to-chat is separate from workflow references. The chat should show image
  attachment chips that can be removed. A chat attachment becomes a generation
  reference only after the user explicitly selects it and presses **Use as reference**.
- Keep current asset-generation prompt provenance, workflow validation, GPU/runtime
  safeguards, one-job behavior, and job recovery. Do not connect this page to story
  Assisted manual or Fully automated video runs.

## Folder access, data handling, and deletion

- Prefer the browser's user-gesture folder picker on the local app. Use its directory
  handle to enumerate supported image files recursively and to write the final image
  into the chosen output folder. Provide a clear unsupported-browser/error state if
  folder access is unavailable; do not silently substitute the current workspace.
- Reference file reads must remain scoped to the chosen reference folder. Do not
  follow symlinks outside that folder. Validate image types and size before staging
  selected reference bytes for the existing ComfyUI input path. Remove temporary
  reference staging files when the associated job no longer needs them.
- ComfyUI and the worker require temporary generated bytes and job metadata while a
  job runs. They are held in a unique transient workspace, not the visible project or
  standalone library. After output validation, write the final bytes to the chosen
  folder, verify the hash, and remove tagged output/reference assets. If export fails,
  retain the temporary copy for recovery and tell the user; never report success
  before the selected-folder file is written and verified.
- Permanent deletion is explicit and guarded: show the exact selected file count and
  paths, require confirmation, and delete only image files inside the chosen folder
  tree. Never delete the reference folder itself or files outside its canonical root.
  Report per-file failures and refresh the gallery after the operation.
- The reference folder and output folder are separate choices. Ask the user to pick
  a folder when needed; this implementation does not persist directory handles or
  file contents.

## UI plan

- Replace Text to Image's current story-workspace destination dropdown with an output
  folder chooser and visible selected-folder name/path. The image gallery below shows
  only the chosen reference folder, not images from the currently selected story.
- Keep the Text to Image folder gallery in its own collapsed disclosure. On
  Characters, Worlds, and Frames, place it in a separate collapsed disclosure below
  the Workflow details disclosure.
- Gallery controls: folder chooser, refresh, image search/filter, newest/oldest,
  cards/list/table, select all shown, deselect all, selected count, delete selected,
  and **Use as reference**. Disable that last action when the selected workflow cannot
  accept images or the reference count exceeds its limit.
- Prompt chat uses the shared `ModelSelector`, supports `/model` and `/status`, and
  displays removable image attachment chips. Dragging a gallery card into chat adds
  that file as a chat attachment; it does not bypass explicit reference selection.
- Keep generated preview and output-folder save status visible. If the chosen output
  filename already exists, ask whether to overwrite; otherwise offer a unique name.

## Implementation record

`LocalImageFolderBrowser.tsx` and its stylesheet implement recursive scanning of the
chosen folder tree, image cards/list/table, filtering, date ordering, selection,
confirmed permanent deletion, drag-to-chat, and a separate workflow-aware **Use as
reference** action. Selected image files are uploaded only after explicit reference
selection.

Text to Image uses a per-session transient workspace isolated from story and
standalone galleries. Its result is written to the selected output folder and hash
verified before tagged output/reference assets are deleted. Failed saves retain a
recovery copy. Reference IDs/tokens restore across page reloads. The shared model
selector and `/model`/`/status` behavior are used. Characters, Worlds and Frames use
the shared resizable, collapsible two-pane workspace: creation controls on the left,
and a right-side stack with separate Workflow details, Reference folder images, then
Director chat. The chat suggests prompt changes for review and never starts generation.
Folder refs are temporary and enabled only for Qwen Image Edit 2511.
