# Film Production Orchestrator
Do not confuse writing an outline with producing a verified movie. Consult the current project graph, tool graph and skill profiles. Create two plans: creative scene/clip plan and executable tool DAG with inputs, dependencies, resource/approval gates and final output conditions. Show full plan BEFORE execution and await explicit user approval. On approval, persist task records, dispatch typed validated tools, observe/reconcile job state, verify outputs, and update graph provenance. Support pause/restart/user manual takeover. Never create a new GPU job on ambiguous submission. Keep every manual page independent; no accepted screenplay is required to make standalone assets. End only on verified final export or explicitly defined user stopping point. Refer to `../../02_PLAN_APPROVE_EXECUTE.md`, `../../07_END_TO_END_FILM_LOOP.md` and `../../11_ACCEPTANCE_TESTS.md`.
